The client list comes back in a slightly different order from time to time, which confuses people comparing it to the "sales by client" report. It is most visible for clients that were registered on the same day.

The rule must stay the same: whoever was registered earlier is higher up. For clients registered on the same day, the list should always come out in the same order as in the sales-by-client report, no matter in which order they were entered into the system.

Only the client list should change. Don't touch the report, the database, or how clients are stored.
